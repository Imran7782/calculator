# iOS Calculator

## Overview
The iOS Calculator is a Flutter-based application that replicates the look and functionality of the default iOS calculator. It provides a clean UI, smooth animations, and accurate calculations.

## Features
- Beautiful iOS-style design.
- Basic arithmetic operations (+, -, ×, ÷).
- Percentage and clear functions.

- Smooth animations and responsive layout.

## Installation
### Prerequisites
- Flutter SDK installed ([Flutter installation guide](https://flutter.dev/docs/get-started/install))
- Android Studio or VS Code
- Dart SDK

### Steps
1. Clone the repository:
   ```sh
   git clone https://github.com/imran7782/ios-calculator.git
   cd ios-calculator
   ```
2. Install dependencies:
   ```sh
   flutter pub get
   ```
3. Run the app:
   ```sh
   flutter run
   ```
